# Windows Server Administration

## Project Overview

This project demonstrates practical experience in administering, maintaining, troubleshooting, and supporting Windows Server environments within an enterprise IT infrastructure.

The work covers Windows Server deployment, Active Directory integration, DNS, DHCP, Group Policy, file services, user administration, server monitoring, patch management, security, backup support, troubleshooting, and technical documentation.

The project is presented as a generalized professional case study without exposing confidential organizational information.

## Server Troubleshooting

A structured troubleshooting methodology was used for Windows Server incidents.

### Troubleshooting Workflow

1. Identify the affected server or service.
2. Determine the business impact.
3. Review the reported symptoms.
4. Check server availability.
5. Review system and application events.
6. Check CPU, memory, and disk utilization.
7. Verify relevant services.
8. Check network connectivity.
9. Verify DNS and DHCP where applicable.
10. Check Active Directory dependencies.
11. Apply corrective action.
12. Test the affected service.
13. Confirm service restoration.
14. Document the resolution.
15. Monitor for recurrence.
